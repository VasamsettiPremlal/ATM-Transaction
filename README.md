ATM Kiosk Transaction System
📌 Project Description

The ATM Kiosk Transaction System is a simple Python program that simulates basic ATM operations.
The user enters a language and ATM PIN to log in. After successful authentication, the user can perform basic banking transactions such as:

Check account balance

Withdraw money

Deposit money

Exit the system

This project is useful for beginners to understand Python conditional statements, input/output, and basic banking logic.

⚙️ Features

User login using ATM PIN

Menu driven interface

Check account balance

Withdraw money with balance verification

Deposit money

Simple transaction messages

🛠️ Technologies Used

Python 3

Concepts used:

input() function

if-elif-else conditions

Variables

Basic arithmetic operations
